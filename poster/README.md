# APIRIA Scientific Poster — Von Hippel–Lindau Disease

## File

**`VHL_Multisystem_Imaging_Poster.pptx`** — fully editable PowerPoint poster

## Specs

| Property | Value |
|---|---|
| Orientation | Landscape |
| Aspect ratio | 16:9 |
| Slide size | 36.571" × 20.571" (optimized for 42" LCD) |
| Format | Native PowerPoint shapes & text boxes |

## How to use

1. Open in Microsoft PowerPoint (or compatible).
2. Replace **Institution Logo** and **Conference Logo** placeholders with your logos.
3. Replace each **Insert Radiology Image** area with the corresponding scan:
   - CT Abdomen
   - MRI Cervical Spine
   - MRI Thoracic Spine
   - Hemangioblastoma
   - Pancreatic Cysts
   - Renal Cysts
4. Fill in the three reference placeholders if needed.
5. Optional: change font to Inter / Aptos / Segoe UI / Helvetica (Calibri used for cross-platform compatibility).
6. Export to PDF via **File → Export → Create PDF** (layout is export-ready).

## Regenerating

```bash
python3 poster/generate_poster.py
```

## Content source

All scientific content is taken from the poster abstract (APIRIA – 204). Reference citation lines are editable placeholders because no numbered bibliography was supplied in the source text.
